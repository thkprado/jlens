# Sample documents

The JSONata examples of the book (`jsonata-example` blocks) run against these documents;
`cargo xtask doc-check` verifies every one of them.

| File | Contents |
|---|---|
| `address.json` | A person with an address, phone numbers and e-mail addresses |
| `invoice.json` | An account with orders of products |
| `library.json` | Books, loans and customers |

They come from the JSONata documentation and test suite, © IBM Corp. and JSONata contributors,
MIT license.
